## Time Series Studio powered, on-device learning Fan anomaly detection based on FRDM-MCXA156

An application designed for monitoring the status of a fan, or other vibration source, which utilizes an accelerometer sensor attached to the fan to check if the fan is operating in a normal condition.

Application runs on a FRDM-MCXA156 with 96MHz Cortex-M33, 1M Flash and 128KB SRAM. 

The Application is powered by an IKM (Incremental KMeans for anomaly detection) model, which was trained and generated by [eIQ Time Series Studio](https://www.nxp.com/products/processors-and-microcontrollers/arm-microcontrollers/eiq-time-series-studio-for-edge-ai-development:eIQ-TSS). The model supports on-device learning as well.

Model size is 7 KB and only uses 4KB of RAM. Model inference time is 6ms. 

For details on how the model was trained, please refer to [AN14549](https://www.nxp.com/docs/en/application-note/AN14549.pdf)

## 2. Hardware<a name="step2"></a>

- [FRDM-MCXA156](https://www.nxp.com/part/FRDM-MCXA156)
- [LCD-PAR-S035](https://www.nxp.com/design/design-center/development-boards-and-designs/general-purpose-mcus/3-5-480x320-ips-tft-lcd-module:LCD-PAR-S035)
- Accelerometer:
  - [6DOF-IMU-20-Click](https://www.mikroe.com/6dof-imu-20-click) (Recommended and default for project) or
  - [ACCEL-4-CLICK](https://www.mikroe.com/accel-4-click)

- Fan or vibration source
- Type-C USB cable

## 3. Setup<a name="step3"></a>

### 3.1 Step 1

- Plug in LCD-PAR-S035 LCD into the FRDM-MCXA156 (J8)
  
  ![](image/lcd_connect.jpg)

- Mount 6DOF-IMU-20-Click or ACCEL-4-CLICK board to the FAN with sticky tape
  
  ![](image/fan.jpg)

- Use jumper wires to connect FRDM-MCXA156 to the 6DOF-IMU-20-Click or ACCEL-4-CLICK
  
  ![](image/sensor_connect.jpg)

- Connect a USB-C cable to the debug port
  
  ![](image/debug.jpg)

- Completed System
  
  ![](image/system.jpg)

### 3.2 Step 2

Import "dm-tss-powered-on-device-learning-fan-anomaly-based-on-mcxa156" from Application Code Hub

- Import project in MCUXpresso IDE
  
  ![](image/mcux%20_import_project.png)

- Import project in VS code
  
  ![](image/vs_import_project.png)

- Select IMU sensor in **sensors/accel_sensor.h** (default IMU is Bosch BMI323 on the 6DOF-IMU-20-CLICK)

    `/*! @brief Selector value for the FXLS8974CF (ACCEL-4-CLICK). */`
    
    `#define ACCEL_SENSOR_FXLS8974 (1)`

    `/*! @brief Selector value for the Bosch BMI323 (6DOF-IMU-20-CLICK). */`

    `#define ACCEL_SENSOR_BMI323 (2)`

    `#ifndef ACCEL_SENSOR_SELECT`

    `#define ACCEL_SENSOR_SELECT ACCEL_SENSOR_BMI323`

    `#endif`


- Build project and download to the board

  - **Notice: please erase the whole flash before download the firmware**
- Open serial terminal for 230400 baud (optional)


## 4. Results<a name="step4"></a>

### Training on Device

- Turn on the fan to the desired speed that should be considered "Normal"

- Enter Trainer screen and click the Start button to begin training. Ensure that you do not move the fan during the training procedure. If first time training set the "Train from beginning" option. 
  
  ![](image/trainer.jpg)

- Return to main after training is complete and it should recognize that fan speed as "Healthy". If need by try training again but leave off the "Train from beginning" option. 
  
  ![](image/trained_result.jpg)


### Testing 
- If fan changes speeds then will get anomaly. But if set back to original fan speed it was trained on, then will read "Healthy" 
  
  ![](image/normal.jpg)

- If knock on the fan, an anomaly will be detected
  
  ![](image/anormaly1.jpg)

- If insert an object into the fan blades, an anomaly will be detected
  
  ![](image/anomaly2.jpg)

- If modify the angle of the accelerometer by rotating the fan by 90 degrees, an anomaly will be detected.
  
  ![](image/anormaly3.jpg)
